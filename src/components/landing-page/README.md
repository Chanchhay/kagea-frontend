# Landing Page Copy Guide

To copy this landing page into another project, copy:

- `src/components/landing-page/`
- `public/images/components/company-logo/`
- `public/images/testimonials/`
- `public/images/logo.png`
- `public/images/istad.png`
- `public/images/purple-moon-bg.png` if you use `Hero.tsx`

This package expects these dependencies in the target project:

- `next`
- `react`
- `react-dom`
- `framer-motion`
- `motion`
- `gsap`
- `react-intersection-observer`
- `three`
- `@react-three/fiber`
- `@react-three/drei`
- `clsx`
- `tailwind-merge`

It also expects Tailwind CSS to be configured in the target project.
