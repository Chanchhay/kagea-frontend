About this role

TechSphere Innovations is seeking a highly skilled and motivated Fullstack Developer to join our dynamic engineering team. In this role, you will play a critical part in designing, developing, and maintaining scalable web applications that power our core business services.

You will bridge the gap between robust backend architecture and seamless, interactive frontend user experiences.

Qualification

  • Bachelor's degree in Computer Science, Software Engineering, or a related technical field.
  • 3+ years of proven experience in full-stack web development.
  • Backend — strong proficiency in Java (11+) with Spring Boot, Spring Security, and Spring Data JPA.
  • Frontend — deep understanding of JavaScript (ES6+), HTML5, CSS3, React and Next.js.

Responsibility

  • End-to-end development — design, build, and maintain both server-side logic and client-side web applications.
  • Backend architecture — develop robust, secure, scalable RESTful APIs and microservices.
  • Database management — design data models and manage relational databases (PostgreSQL, MySQL).
  • Collaboration — work closely with product managers, designers, and other developers.
  • Code quality — participate in peer reviews and write comprehensive unit and integration tests.
